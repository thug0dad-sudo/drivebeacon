# Prototype Requirements

## Core functions
- Detect likely texting/distraction
- Warn driver locally
- Log events
- Send parent/fleet notifications
- Trigger external visible signal

## Hardware concept
- Cabin camera or sensor module
- Processing unit
- LED / visible exterior indicator
- Companion app or dashboard

## Software
- On-device inference preferred
- Event logs
- Risk scoring
- Settings for sensitivity and privacy

## Testing stages
1. Paper prototype
2. Bench prototype
3. Closed-course test
4. Private pilot
5. Launch readiness

## Safety requirements
- No emergency-light imitation
- Conservative escalation
- Privacy defaults on
- Clear consent settings
