# DriveBeacon Prototype Spec

## Goal
Build a working prototype that detects likely texting/distraction, warns the driver, logs events, and supports optional external signaling.

## Core modules
- sensor input / camera module
- on-device detection
- event logger
- alert system
- external visible signal
- admin dashboard

## MVP requirements
- detect likely distraction events
- alert driver first
- store timestamps and severity
- export summaries
- configurable privacy controls

## Testing
- desk demo
- vehicle bench test
- closed-course test
- private pilot

## Safety/compliance
- no emergency-light imitation
- conservative thresholds
- clear consent and privacy settings
- legal review before public launch
